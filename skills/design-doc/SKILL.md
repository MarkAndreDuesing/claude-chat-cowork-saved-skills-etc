# Design doc

Fill `template.md` (next to this file) for the requested feature or change. Fill every section; mark a section that
doesn't apply `N/A` with a short reason instead of deleting it. Sections 2 and 4 are for software; for other work,
replace them with the parts and checks that apply, or mark them `N/A`.

Research first (sources, related work, existing patterns); put the sources in the document. Unverified points go
into "Open questions", not into the design. The `communication` skill rules apply.
