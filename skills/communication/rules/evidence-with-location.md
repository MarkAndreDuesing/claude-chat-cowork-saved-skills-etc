# Evidence with exact location
- Back claims about code or documents with a short snippet or quote.
- Give its exact location: repository, branch or commit when relevant, `file:line`, and the named part (class, method, function, stage, section, heading).
- Never refer vaguely ("the config", "the pipeline file") when several candidates exist.
- Give every local file or folder as a complete absolute path. Never a partial path or a description of where it is ("the folder next to it").
- Cite a source for every factual claim: absolute path with line number, commit as full URL, ticket or document as URL.
- Mark inferences as inferences (e.g. "intended" when only the author is known).
