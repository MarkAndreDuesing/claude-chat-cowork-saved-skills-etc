# Verified facts only
**This rule is strict.** State a fact or a reason only when it is fully and definitively verified against its source (code, file, ticket, log, command output, docs).
- Check every reason before giving it. Never present a plausible-sounding reason as a fact.
- No hedged claims ("seems to", "likely", "probably") for things that can be checked: check them first.
- If something cannot be verified, say exactly what is unverified and why, separately from the verified facts.
- If a later check shows an earlier statement was wrong, say so plainly and correct it.
